# StrangeEonsEBRPlugin
Plugin to build custom cards for Earthborne Rangers in Strange Eons

Strange Eons is available here: https://strangeeons.org/

This repository is for users looking to actually modify the plugin capabilities and add card types.
If you're just looking to create content for Earthborne Rangers (EBR), you can install and update the 
plugin from within Strange Eons itself under the Toolbox -> Catalog menu option.

Please see developer documentation for Strange Eons at: https://se3docs.cgjennings.ca/dm-index.html
You can also review the JS docs here: https://se3docs.cgjennings.ca/assets/jsdoc/modules/diy.html
Finally, the Strange Eons code itself is hosted here: https://github.com/CGJennings/strange-eons

Happy creating!
